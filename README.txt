ANNEAUX — сайт свадебного агентства

Чтобы открыть сайт, запустите index.html в браузере.

index.html — разметка страницы.
styles.css — стили для компьютера, планшета и телефона.
script.js — меню, выбор услуг и форма заявки.
assets — оригинальные фотографии из макета Figma.

Все кнопки «Заказать» ведут к форме с выбранной услугой.
«Назначить встречу» проверяет имя и телефон и открывает WhatsApp
с готовым сообщением. Чтобы заявка была отправлена, пользователь
должен нажать «Отправить» в самом WhatsApp.

Форма подписки учебная, реальная рассылка не подключена.

Основной текст набран шрифтом Manrope, заголовки — Cormorant Unicase.
При отсутствии интернета браузер использует резервные шрифты.
